# JDIH PT Gresik Migas Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Satu aplikasi Laravel + Inertia React yang melayani portal publik JDIH dan arsip dokumen internal per divisi dengan persetujuan dua tahap.

**Architecture:** Monolit Laravel. Aturan visibilitas hidup di satu tempat (`DocumentPolicy` + `Document::scopeVisibleTo`), perpindahan status di satu service (`DocumentWorkflow`); controller dan halaman React hanya memanggil keduanya. Berkas PDF di disk privat dan selalu dilayani lewat controller.

**Tech Stack:** Laravel (stabil terbaru) di PHP 8.5, starter kit resmi React (Inertia, TypeScript, Tailwind, shadcn/ui, lucide-react), PostgreSQL 18, Pest.

**Spec:** `docs/superpowers/specs/2026-10-13-jdih-ptgm-design.md`. Baca seluruhnya sebelum mulai; nomor bagian di bawah merujuk ke sana.

## Global Constraints

- Nilai enum disimpan sebagai string, divalidasi enum PHP. Tidak memakai enum bawaan database, `ILIKE`, atau jsonb. Pencarian memakai `whereLike`.
- Peran: `karyawan`, `manajer`, `gm`, `admin`. Akses: `publik`, `divisi`. Status: `draf`, `menunggu_manajer`, `menunggu_gm`, `disetujui`, `ditolak`. Jenis relasi: `mengubah`, `mencabut`, `menggantikan`, `terkait`.
- Satu PDF per dokumen, maksimal 20 MB, di disk `local` (privat). Tidak ada URL berkas publik.
- Akses yang tidak diizinkan menghasilkan 403, baik halaman detail maupun unduhan.
- Tidak ada registrasi mandiri dan tidak ada lupa password mandiri.
- Seluruh teks antarmuka berbahasa Indonesia.
- Warna: indigo `#30318B` (utama), biru langit `#00A2EA` (aksen, bukan untuk teks di atas putih). Huruf: Source Serif 4 (judul), Public Sans (antarmuka), dipasang lokal.
- Tidak memakai: gradien, efek kaca, emoji sebagai ikon, kartu statistik berikon, hero dengan slogan, bayangan pada kartu, warna ungu, sudut di atas 6 px.
- Kontras teks minimal 4,5:1, fokus keyboard terlihat, label form selalu tampil, layak pakai dari lebar 375 px, hormati `prefers-reduced-motion`.
- Skill saat mengerjakan UI: `ponytail`, `emil-design-eng`, `impeccable`, `ui-ux-pro-max`.

## Review Focus

1. Berkas unggahan bukan PDF asli (ekstensi diganti), kosong, atau di atas 20 MB: ditolak dengan pesan di dekat kolom, draf tidak tersimpan setengah. Tes di Task 5.
2. Dua orang memutuskan dokumen yang sama, atau keputusan dikirim dari tab lama setelah status berubah: keputusan kedua ditolak dengan pesan jelas, tidak ada transisi ganda. Tes di Task 4.
3. Divisi tanpa akun Manajer: pengajuan Karyawan ditolak dengan pesan "Divisi belum memiliki manajer. Hubungi Admin.", bukan menggantung selamanya. Tes di Task 4.
4. Jawaban AI cacat: JSON rusak, tanggal bukan `YYYY-MM-DD`, jenis di luar daftar, kolom hilang. Kolom yang sah tetap terisi, sisanya kosong, form tidak galat. Tes di Task 10.
5. ID relasi dimanipulasi ke dokumen yang tidak boleh dilihat pengaju, atau ke dokumen itu sendiri: validasi menolak. Tes di Task 5.
